# Data

This directory contains dataset documentation and local dataset files.

The raw and processed datasets are not committed to GitHub.

## Dataset

The project uses public Persian sentiment datasets, primarily:

- SnappFood sentiment dataset
- Digikala reviews dataset for domain-shift evaluation

## Data Policy

Dataset files are stored locally or in the execution environment and are excluded from Git tracking.

Dataset source, license, split information, and download instructions will be documented here.
